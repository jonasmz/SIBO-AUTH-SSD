# Contract: OpenAPI Coverage and Exposure

The document is generated by `Microsoft.AspNetCore.OpenApi` (OpenAPI 3.1, document name `v1`)
from endpoint metadata. Adding metadata MUST NOT change any endpoint's behavior. Every response
listed below is one the endpoint already returns; error bodies are `application/problem+json`.

## Exposure

| Environment | `GET /openapi/v1.json` | `GET /scalar` (and assets) | Through the frontend |
|---|---|---|---|
| Development | 200, the document | 200, read-only viewer | n/a (development runs directly) |
| Production | 404 | 404 | never routed (only `/auth/api/*`) |

Viewer: test-request button hidden, API client hidden, no persistent authentication, no preset
credentials, telemetry off.

## Security scheme

`components.securitySchemes.Bearer`: `type: http`, `scheme: bearer`, `bearerFormat: JWT`. Operations
marked **Bearer** carry a `Bearer` security requirement; anonymous operations carry none.
